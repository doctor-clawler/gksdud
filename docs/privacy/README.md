# 개인정보 처리 기준

[공통 SDK·처리 계약](https://github.com/WithClawler/_ops/blob/feat/ops-v2-safe-supervision/docs/privacy/contract.md) (`mib-privacy/1`)을 적용합니다.
[앱별 manifest](manifest.json)는 이 저장소의 실제 처리 근거와 미확정 항목을 관리합니다.

현재 기록은 공통 기준 연결과 SDK/권한 검색 근거입니다. 수집 여부·법적 근거·
최종 APK·삭제·민감 권한·공개 정책이 검증됐다는 의미가 아닙니다. `release_ready=false`를
유지하며 다른 앱의 정책/연령/보존 값을 복사하지 않습니다.

운영자 확인 전 다른 프로젝트의 사업자/메일 주소를 자동으로 적용하지 않습니다.
확인된 밉스튜디오 앱의 문의처는 support@mibstudio.top이며 실제 메일 수신 확인 전
quxn6@naver.com을 함께 유지합니다.
